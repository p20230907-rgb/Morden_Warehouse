LLM Only Assistant (Entity Extraction)

This mode uses the LLM to **extract specific entities** (like item names or shelf IDs) from your query and then performs a direct lookup in the database. It does **not** use RAG (Retrieval-Augmented Generation) for contextual answering. Ideal for precise, known queries.
